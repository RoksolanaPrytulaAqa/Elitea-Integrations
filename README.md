# Quiz CLI

Quiz CLI is an interactive command-line quiz game designed to test and enhance your JavaScript programming knowledge. The application demonstrates modern JavaScript features such as ES Modules, async/await, Promises, file system operations, and object-oriented programming concepts. It provides an engaging way to learn and practice programming.

## Features
- Interactive CLI-based quiz.
- Demonstrates JavaScript concepts:
  - ES Modules (import/export).
  - Async/await and Promises.
  - File system operations.
  - User input handling.
  - Classes and object-oriented programming concepts.
  - Utilizes advanced JavaScript techniques such as array methods, destructuring, template literals, and error handling.
- A library of quiz questions loaded from a JSON file.
- Various categories and options for the number of questions to attempt.

## Project Structure
The repository consists of the following files:
- `index.js`: Main script for the Quiz CLI. Handles user interactions and quiz logic.
- `package.json`: Contains metadata about the project such as name, version, description, and dependencies.
- `.DS_Store` and associated files: macOS metadata files (non-functional for the project).
- `test-app.zip`: Zipped test application (contents purpose unclear).

## Getting Started

Follow these steps to set up and run the Quiz CLI:

### Prerequisites
- Ensure you have [Node.js](https://nodejs.org) (version >= 18.0.0) installed on your system.

### Installation
1. Clone the repository:
    ```bash
    git clone <repository_url>
    cd <repository_name>
    ```
2. Install dependencies:
    ```bash
    npm install
    ```

### Running the Quiz CLI
To start playing the quiz, use the following command:
```bash
npm run start
```
